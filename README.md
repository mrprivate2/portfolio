## 🖥️ About The Project

This project is my personal interactive developer portfolio, built with a **desktop/operating-system-inspired interface**.

Instead of presenting information through a conventional landing page, the portfolio provides a virtual desktop where different sections of my profile are represented as applications and desktop icons.

The goal is to combine **professional portfolio presentation with modern UI/UX, interactivity, and a unique developer-focused experience**.

# 🎨 Design Philosophy

The design combines three ideas:

### 1. Developer Desktop

The portfolio behaves like a personal operating system rather than a static website.

### 2. Cybersecurity Aesthetic

The dark interface, terminal elements, system indicators, and green accent color are inspired by modern cybersecurity and developer environments.

### 3. Professional Simplicity

Despite the interactive experience, the interface keeps the important information easily accessible to recruiters.

# ⚙️ Getting Started

## Prerequisites

Make sure you have installed:

* Node.js
* npm
* Git

Check your installation:

```bash
node --version
npm --version
git --version
```

---

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/mrprivate2/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Run Locally

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.

With Vite, it will typically be:

```text
http://localhost:5173
```

---

# 🏗️ Build For Production

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

# 🔐 Security & Privacy

This portfolio is designed as a frontend-focused personal website.

No sensitive personal information, credentials, API keys, or private configuration should be committed to the repository.

Before pushing changes:

```bash
git status
```

Make sure `.env` and other sensitive files are excluded through `.gitignore`.
